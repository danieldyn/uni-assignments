# Communication Protocols
# -- Assignments --

This directory features my implementation for two Communication Protocols assignments:

- Router dataplane
- Media transmission protocol over UDP

Languages: C, C++

The `roter-dataplane` and `media-transmission` subdirectories also contain a `README.md` file with a summary of the solved tasks,
according to the limitations, assumptions and purpose of the tasks. These assignments were designed to implement custom protocols for
special use cases based on the purposes of all five layers of the TCP/IP network stack.
