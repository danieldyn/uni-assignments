# Programming Paradigms
# -- Assignments --

This directory features my implementation for two Programming Paradigms assignments:

- Shopping simulator
- Functional graphs

Languages: Racket, Haskell

The `shopping-sim` and `functional-graphs` subdirectories also contain a `README.md` file with a summary of the solved tasks,
according to the limitations, assumptions and purpose of the tasks. These assignments were designed to gradually apply the core
features of functional programming to optimise the implementation from the previous part (four parts in total).
